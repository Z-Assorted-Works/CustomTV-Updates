# Custom TV updates

Public APK downloads and update-channel metadata for Custom TV. The application source is maintained in a separate private repository.

- LIVE: releases ready for general use.
- PRE-RELEASE: earlier testing builds; the TV may also offer a newer LIVE release.

Choose the channel in Custom TV Settings. Only versions newer than the installed build are offered. Updates use Android's normal installation approval and work over Wi-Fi or Ethernet without wireless debugging after the initial updater installation.

The `channels.json` feed is published after the APK is verified. Promotion to LIVE reuses the same version and APK. This repository has its own metadata-only history; it contains no source checkout or private repository credentials.
