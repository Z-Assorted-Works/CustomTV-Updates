# Recommended programme data

The `tvmaze-top-rated.json` catalogue is derived from [TVmaze](https://www.tvmaze.com), using its [public API](https://www.tvmaze.com/api) and highest-rating programme listing. This data is distributed under [Creative Commons Attribution-ShareAlike 4.0](https://creativecommons.org/licenses/by-sa/4.0/).

Changes: selected 30 highly rated titles with at least 100 votes from the first 100 highest-rating results, retained title/rating/vote count/poster/source links, and normalized the programme metadata for Custom TV. Retrieval time and source URLs are included in the JSON. This is a curated snapshot and does not assert regional or app streaming availability.

The Custom TV Recommended page credits TVmaze and links to each programme's source and the data licence. Programme posters remain linked to their source host. The application source remains private in a separate repository; this public repository contains downloads, attributed data and update metadata only.
